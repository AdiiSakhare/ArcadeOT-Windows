# Data contract and destinations

Measurement fields use PascalCase in this first implementation: EventId (stable on retries), SiteId, PlcId, SensorId, ConfigRevision, ObservedAtUtc, SourceAtUtc (nullable), RawValue, Value, Unit, Quality, Error and RawHex. Keep raw bytes separately from decoded value. Bad communication/timeout/decoding results have null Value; never substitute zero. Bool is JSON Boolean. Numeric scaling currently returns a JSON number represented by double; arbitrary 64-bit exact integer ingestion requires a future typed-value schema. Nonfinite floats become BadDecode/null with RawHex retained. Range failures retain value with UncertainRange.

SQLite has event_id PRIMARY KEY, observed_utc, payload JSON text and acknowledged flag, plus pending index. Insert and outbox eligibility are one durable row transaction. WAL and synchronous FULL are configured; there is no claim that the filesystem/hardware survives arbitrary power loss without testing. Backup uses SQLite backup API or stop the service and copy the consistent database with its state; copying a live DB alone is insufficient.

HTTPS POST sends {schemaVersion:1, measurements:[...]} batches up to 100. Server must authenticate bearer credentials, verify that credentials authorize every SiteId, validate size/types/quality, transactionally insert using EventId uniqueness, and return {acceptedEventIds:[...]} only after commit. Repeated event ID with different payload is a conflict/quarantine case, not a silent update. Return partial ACK only for committed rows. Service acknowledges only returned IDs that were actually sent. All unacknowledged events remain pending on failure; fixed 5-second retry is implemented (jitter/backoff/permanent-error quarantine still future work).

PostgreSQL DDL is supplied; other SQL databases need dialect adapters and equivalent uniqueness. Direct database credentials are not embedded in the UI. CloudUrl and token are installation settings; HTTPS validation uses the OS trust store. No hosted API is provisioned. Future backend/dashboard must enforce tenant/site scope on both reads and writes, bounded time queries and retention. Preserve UTC storage and show local times only in presentation.

Acknowledged rows older than RetentionDays may be deleted. Unacknowledged rows never expire automatically. Used database pages are limited by MaxBufferMb; SQLite can reuse free pages. Free disk reserve is 50 MiB; WAL/backup overhead still needs operational headroom. At quota/reserve breach polling pauses and health exposes the condition; missed PLC states cannot be reconstructed later. For isolated local-only operation export and archive the database regularly; exporting CSV does not acknowledge/delete events.
