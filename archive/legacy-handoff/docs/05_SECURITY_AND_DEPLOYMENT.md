# Security and deployment

The implemented driver can only issue device read command 0401; there are no write/remote RUN/STOP/reset/password-unlock paths. Configuration cannot select an arbitrary command. This is a collector and is not a safety controller. Existing PLC network protections remain a deployment responsibility.

Install service as LocalService, start automatically at boot and configure restart recovery. Install binaries in Program Files; mutable data in ProgramData/ArcadeOT. Installer removes inherited data-folder access and grants SYSTEM/Administrators full control plus LocalService modify using well-known SIDs. First release UI requires elevation; it uses the installation token to call loopback-only API. No remote administration listener or CORS is enabled. Token must not appear in exported configs, CSV or logs. HTTPS cloud token is separate, masked/write-only in the UI and stored in the protected folder. Rotate API token with service restart; cloud token is reread for upload.

Operator/Technician/Admin roles, immutable configuration audit records, encrypted secret protection beyond filesystem ACL, certificate rollover UI, signed packages and least-privilege non-admin desktop IPC remain required production hardening. Do not advertise those features as shipped. No inbound firewall exception should be installed for the local API. PLC traffic is generally unencrypted; restrict network reachability and use site-approved segmentation/remote-access controls. OPC UA or CIP Security requires its own verified device/security implementation; this release does not gain encryption by selecting a brand.

The PowerShell installer is rerunnable and retains data; uninstall unregisters the service and preserves data deliberately. Installer rollback and binary Authenticode signing remain open. Upgrade procedure: stop collection, backup consistent DB/config/credential ACL, close UI, install, verify service/version and mappings, run smoke reads, keep backup for rollback. The Windows runtime is bundled; rebuilding requires .NET 10 SDK. Package restore vulnerability warnings are errors. Pin dependency versions and re-run security audit before future releases.
