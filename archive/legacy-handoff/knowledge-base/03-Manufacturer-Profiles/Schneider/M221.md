# Schneider Modicon M221 / related families

Research-backed candidate; no Schneider-specific or Modbus driver implemented here. M221 Ethernet-equipped references and serial-only references must be separated. Use Modbus TCP only on a CPU/interface that actually has supported Ethernet server capability; use serial settings from the exact model for RTU.

Official mapping FAQ identifies %M with Modbus bit/coils and %MW with word/holding-register classes. Do not assume input %I or analog %IW values are exposed as identical Modbus addresses; exchange mapping may be necessary. Programming Guide v04 is catalogued, but its full PDF body was not inspected in this session, so device-specific function-code limits must be confirmed from that edition before implementation.

Hardware Guide EIO0000003313 v04, 2025-09-01 is the terminal reference. Select exact TM221 order code and terminal/supply/output variant, plus actual expansion modules. M241/M251/M262 use separate manuals/software/features; OPC UA or other services on those families do not establish M221 support. Firmware, server map, unit-ID behavior, request limits and boot settings remain hardware commissioning gates.

Sources: [SCH-HW](https://www.se.com/us/en/download/document/EIO0000003313/), [SCH-PROG](https://www.se.com/us/en/download/document/EIO0000003297/), [SCH-MAP](https://www.se.com/br/pt/faqs/FA341238/). See source register for edition/access depth.
