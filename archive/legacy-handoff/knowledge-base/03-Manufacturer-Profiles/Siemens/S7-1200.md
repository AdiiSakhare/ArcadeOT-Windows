# Siemens S7-1200 / S7-1500 / G2

Research-backed candidate; no Siemens driver in this build. For classic S7 absolute reads require an explicitly planned exchange DB and matching CPU access/security settings. Prefer supported secure/symbolic mechanisms where available rather than broad legacy permissions. S7-1200 OPC UA server availability and user rights are firmware/CPU/license dependent and must be checked in the matched TIA documentation.

Record full 6ES7 order number, firmware, hardware generation, TIA version, CPU protection/access mode, endpoint, exchange DB optimization state or OPC UA namespace/node IDs and server license. OPC UA licensing and firmware minimums are not asserted universal here. S7-1200 G2 appears separately in TIA V21 documentation; its exact feature and firmware matrix remains unresolved in this handoff. S7-1500 must have its own capability row.

Terminal evidence: obtain the exact CPU’s wiring diagram and any SM/SB/CM module manuals through the S7-1200 system documentation. DC/DC/DC versus relay and supply variants can change connections; no generic brand pinout is valid. Prove byte order and physical-to-DB mapping with a PLC monitor and calibrated/known input.
