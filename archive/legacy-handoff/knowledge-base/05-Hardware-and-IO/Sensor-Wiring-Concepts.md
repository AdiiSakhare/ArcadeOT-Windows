# Sensor wiring evidence

For each signal retain sensor datasheet, PLC/module/terminal-block order code, diagram reference, supply/current requirements, common/reference grounding, shielding/isolation and configured range. Electrical work belongs to qualified site personnel following the exact manuals. ArcadeOT stores module/channel references for traceability; its network map is separately confirmed from PLC logic.

See Model-Specific-Terminal-References.md for official manual pointers. Exact terminal numbers and wiring instructions are intentionally not asserted without an identified SKU/module.
